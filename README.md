# Bash-скрипты для автоматизации задач на сервере Linux.
## Что это и зачем?
Этот репозиторий содержит набор Bash-скриптов для начала работы с сервером, если вы хотите его быстро настроить и автоматизировать. Проект подойдёт как для начинающих администраторов (чтобы попрактиковаться в написании скриптов), так и для быстрой настройки домашнего или тестового сервера.

Эти скрипты независимы друг от друга и могут работать раздельно, но лучше использовать их совместно для лучшей защиты и качества работы сервера. Вы также можете изменять/дополнять эти скрипты.
## Список скриптов
1. setup.sh
2. security_check.sh
3. monitor.sh
4. maintenance.sh
5. ssh_report.sh
6. swap.sh
7. cron.sh
